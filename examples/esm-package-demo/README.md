# ESM Package Demo

This example exercises the new `node_modules` support with a real browser-safe ESM dependency.

It uses [`escape-string-regexp`](https://www.npmjs.com/package/escape-string-regexp), which is small, ESM-first, and compatible with the current `packages.mode = "esm-only"` boundary.

Commands:

```sh
npm install
npm run build
```
